## 1. О проекте

**ForgeStore** — это полнофункциональное интернет-магазиновое приложение (SPA), разработанное с использованием современных веб-технологий. Проект включает в себя:

- 🏪 **Витрину магазина** — каталог товаров с поиском, фильтрацией и сортировкой
- 👤 **Система авторизации** — регистрация, вход, личный кабинет
- 🛒 **Корзина покупок** — управление товарами, оформление заказа
- 📊 **Админ-панель** — аналитика, управление товарами и пользователями
- 🎨 **Тёмная/светлая тема** — переключение между режимами оформления

Проект использует **FakeStore API** для получения данных о товарах.

## 3. Установка и запуск

### Предварительные требования

- **Node.js** версии 18 или выше
- **npm** (входит в состав Node.js)

### Шаг 1: Клонирование репозитория

```bash
git clone <URL-репозитория>
cd online_shop
```

### Шаг 2: Установка зависимостей

```bash
npm install
```

### Шаг 3: Запуск dev-сервера

```bash
npm run dev
```

После запуска приложение будет доступно по адресу: `http://localhost:5173`

### Шаг 4: Сборка для продакшена

```bash
npm run build
```

Собранные файлы будут в папке `dist/`.

## 5. Руководство по использованию

### 5.1 Регистрация нового пользователя

1. Перейдите на страницу **Register** (или нажмите "Create Account" на главной)
2. Заполните форму:
   - **Email** — ваш email-адрес
   - **Username** — имя пользователя
   - **Password** — пароль
3. Нажмите кнопку **Create Account**
4. После успешной регистрации вы будете автоматически авторизованы

> ⚠️ **Важно**: Если вы зарегистрируетесь с email `admin@gmail.com`, вам автоматически присвоится роль **Admin**!

### 5.2 Вход в систему

1. Перейдите на страницу **Login**
2. Введите email и пароль
3. Нажмите кнопку **Sign In**
4. После успешного входа вы будете перенаправлены на дашборд

**Тестовые учётные данные:**

| Email | Пароль | Роль |
|-------|--------|------|
| `admin@gmail.com` | `admin` | Admin |
| `user@gmail.com` | `user` | User |

### 5.3 Навигация по магазину

#### Главная страница (Home)
- Баннер с призывом к действию
- Рекомендуемые товары
- Категории товаров

#### Магазин (Shop)
- Полный каталог товаров
- **Поиск**: введите название товара в строку поиска
- **Фильтр по категории**: выберите категорию из выпадающего списка
- **Сортировка**: выберите порядок сортировки (по возрастанию/убыванию цены или рейтинга)
- **Пагинация**: используйте кнопки для перехода между страницами

#### Карточка товара
- Нажмите на карточку товара, чтобы открыть детальную страницу
- Просмотрите описание, цену, рейтинг
- Выберите количество и нажмите **Add to Cart**

### 5.4 Работа с корзиной

1. Добавьте товары в корзину со страниц магазина или детальной страницы товара
2. Перейдите в **Cart** (иконка корзины в навигации)
3. На странице корзины вы можете:
   - Изменить количество товара (кнопки + / -)
   - Удалить товар (кнопка 🗑️)
   - Очистить всю корзину (кнопка **Clear Cart**)
4. Общая сумма рассчитывается автоматически

### 5.5 Личный профиль

1. Перейдите в **Profile** (доступно только для авторизованных пользователей)
2. Здесь вы можете:
   - Просмотреть информацию о своём аккаунте
   - Увидеть историю заказов (в будущем)

### 5.6 Админ-панель

> ⚠️ Доступно только для пользователей с ролью **Admin**!

#### Дашборд (Dashboard)
- Просмотр аналитических данных
- График выручки по дням
- Круговая диаграмма распределения товаров по категориям
- KPI-карточки: общая выручка, количество заказов, пользователей

#### Управление товарами (Products)
- Просмотр списка всех товаров
- **Добавить товар**: кнопка **Add Product**
- **Редактировать товар**: нажмите на иконку ✏️
- **Удалить товар**: нажмите на иконку 🗑️

#### Управление пользователями (Users)
- Просмотр списка зарегистрированных пользователей
- Информация: ID, username, email, роль, дата регистрации

## 7. Часто задаваемые вопросы

### Как получить права администратора?

При регистрации с email `admin@gmail.com` вам автоматически присвоится роль администратора.

### Сохраняются ли данные после закрытия браузера?

Да, данные о пользователе и корзине сохраняются в LocalStorage браузера.

### Как переключить тему оформления?

Нажмите на иконку солнца/луны в навигационной панели для переключения между тёмной и светлой темой.

### Где хранятся данные о товарах?

Данные о товарах загружаются из внешнего API (FakeStore API). Локальные изменения в товарах сохраняются в LocalStorage.

### Как очистить корзину?

На странице корзины нажмите кнопку **Clear Cart** для удаления всех товаров.
